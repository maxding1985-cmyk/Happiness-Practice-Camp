# 幸福福祉总览

这份资料根据你提供的图片整理出 10 条“幸福路径”：

1. 意义之路
2. 正念之路
3. 运动之路
4. 疗愈之路
5. 失败之路
6. 自愈之路
7. 关系之路
8. 自醒之路
9. 接纳之路
10. 感恩之路

## 说明

- 这些中文名称来自你提供的图片。
- 我在内容上结合了哈佛幸福学代表人物 Tal Ben-Shahar（沙哈尔教授）的幸福学理念来扩展整理。
- Tal Ben-Shahar 官方更常使用的是 **SPIRE** 框架，也就是五个相互联动的福祉维度：
  - Spiritual：精神/意义福祉
  - Physical：身体福祉
  - Intellectual：认知/成长福祉
  - Relational：关系福祉
  - Emotional：情绪福祉
- 因此，这 10 条路径可以理解为：在 SPIRE 五大福祉上的更细化、更加适合日常实践的“幸福入口”。
- 其中你选择的 **意义福祉**，在 SPIRE 里最接近 Spiritual wellbeing，也就是“意义、目的感、价值感、超越自我”的维度。

## 你可以怎么使用这套资料

- 先从 `01-意义之路.md` 开始，作为你当前重点修炼的主线。
- 每周只选 1 到 2 条路径做练习，不要同时推进全部内容。
- 每个文件都包含：核心理解、为什么重要、实践方法、反思问题和参考资料。
- 如果你愿意，后面我们还可以继续把这套资料扩展成：
  - 每周练习版
  - 打卡版
  - 课程讲义版
  - 更适合带领他人的分享版
